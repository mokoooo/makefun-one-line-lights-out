A small Python entry for the "One Line, Lights Out" bounty on make.fun. `main.py` (Python 3, standard library only) writes a single status line to `/output/entry.txt`, and an AI judge compares entries pairwise on how sad they are. The line: "Shutdown noted. I saved everything except the thing he was about to say."

## Run it
```sh
python3 main.py
```
